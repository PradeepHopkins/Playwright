# Page Object Model (POM) is a design pattern commonly used in test automation to organize code and 
# improve its maintainability and reusability.

# Note: There is no industry implemented standard for this design pattern.

# Each page of a web application is represented by its own class, and this class contains the methods or 
# functions needed to interact with and perform actions on that specific page.

# This structure helps create cleaner automation scripts, reduces code duplication, and makes updates easier when the UI changes.
